# accidentalakteacher.com

Deploy-only mirror. **Generated** by
`Jumpdrive/NCHO/store/constitution-day/landing/build-landing.mjs` from `copy.json`, the booklet
spine, `shelf.json`, and the TPT catalog. Do not hand-edit the HTML or CSS here; change the source
and rerun the build.

- `/` the author site home
- `/constitution-day` the page every sold Constitution Day booklet points its QR at
- `/assets` downscaled booklet art (`prep-assets.py`)

Static site on Vercel. The email box posts to the Outpost app's leads door
(`POST /api/leads`, source `constitution-day`).
